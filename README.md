# snowball fight

a side-scrolling shooter/bullet-hell adjacent game set in toronto, but instead of shooting bullets, you run into a group of three miskeens that want to throw lots and lots of snowballs at you. 

why toronto? because i want to go to [horizons polaris](horizons.hackclub.com)

i drew all the art & assets.

background music is claude's plan by jeff guo except i compressed it + added reverb + wind sound effects. i also didn't vibecode this so it's kinda ironic (can you even vibecode godot???)

sound effects are from [zapsplat](https://www.zapsplat.com)! all sounds were edited using [audacity](https://audacityteam.org)

---
made in [godot 4!](https://godotengine.org)

you can clone this project by:
- making a godot project
- opening it in terminal
- running  `git clone https://github.com/ikealoverkat/snowball-fight.git`
